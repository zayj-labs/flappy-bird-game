# 🐦 Flappy Bird Game

A simple Flappy Bird game built with Python and Pygame - perfect for beginners learning game development!

## 🎮 How to Play

- **SPACEBAR** - Make the bird jump
- **R** - Restart the game after game over
- Avoid the green pipes!
- Each pipe you pass = 1 point

## 📋 Requirements

- Python 3.6+
- Pygame

## 🚀 Installation & Setup

1. **Clone this repository:**
   ```bash
   git clone https://github.com/zayj-labs/flappy-bird-game.git
   cd flappy-bird-game
   ```

2. **Install Pygame:**
   ```bash
   pip install pygame
   ```

3. **Run the game:**
   ```bash
   python flappy_bird.py
   ```

That's it! The game window should open and you can start playing! 🎉

## 📝 Game Features

- ✅ Gravity and physics
- ✅ Random pipe generation
- ✅ Score tracking
- ✅ Collision detection
- ✅ Restart functionality
- ✅ Simple controls

## 💡 What You Can Learn

This game teaches you about:
- **Pygame basics** - Creating sprites and handling events
- **Game loops** - How games continuously update and render
- **Collision detection** - Checking when objects hit each other
- **Physics** - Applying gravity and velocity
- **Object-oriented programming** - Using classes for Bird and Pipe
